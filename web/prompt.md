Prompt Spec: AI-Generated Course Flow

Input

User enters only the Course Title (main topic).

Generate Units

When the user clicks Generate Units with AI:

AI generates 5–7 units (subtopics of the main course).

Example for “Introduction to Machine Learning”:

Unit 1: Basics of Machine Learning

Unit 2: Types of Machine Learning

Unit 3: Supervised Learning

Unit 4: Unsupervised Learning

Unit 5: Applications of Machine Learning

Edit Units

Generated units appear in the interface.

User can edit, remove, or add more units.

Auto-Generate Chapters

Once units are finalized, AI automatically generates chapters inside each unit.

Each unit should have 3–5 chapters by default.

Example:

Unit 1: Basics of Machine Learning

Chapter 1.1: What is ML?

Chapter 1.2: History of ML

Chapter 1.3: Real-world examples

Unit 2: Types of ML

Chapter 2.1: Supervised Learning Overview

Chapter 2.2: Unsupervised Learning Overview

Chapter 2.3: Reinforcement Learning Basics

Final Course Structure

User sees a hierarchical course outline:

Title → Units → Chapters (all AI-generated).

User can edit any unit or chapter before saving.

Save Course

On clicking Let’s Go!, the full course (title, units, and chapters) is saved.
