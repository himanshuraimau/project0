# Docker Setup

## Quick Start

```bash
chmod +x docker.sh

# Build and run
./docker.sh build
./docker.sh run
```

App runs at http://localhost:3000

## Commands

```bash
./docker.sh build    # Build image
./docker.sh run      # Run container  
./docker.sh stop     # Stop container
./docker.sh logs     # View logs
./docker.sh restart  # Restart
```

## Requirements

- Docker installed
- `.env` file with all environment variables
